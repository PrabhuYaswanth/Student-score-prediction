# Student Score Prediction Using Machine Learning

## Overview

This project predicts student scores using Machine Learning techniques. The model is trained on student performance data and can estimate the expected score based on input features. The objective of this project is to demonstrate the complete machine learning workflow, including data preprocessing, model training, evaluation, and deployment.

## Features

* Data preprocessing and cleaning using Pandas
* Data analysis and visualization using Matplotlib
* Numerical computations using NumPy
* Machine Learning model development using Scikit-learn
* Score prediction based on user input
* REST API testing and evaluation using Postman
* Trained model saved using Pickle (.pkl)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Flask
* Postman

## Project Structure

* `students.csv` – Dataset used for training
* `student-scoring-system.ipynb` – Data analysis and model training notebook
* `model.pkl` – Trained machine learning model
* `app.py` – Flask application for score prediction
